# 검증 현황 — 2026-10-11

## 실행하여 통과한 검증

`npm test` **12/12 통과**. 실제 AI 응답을 사용한 검증은 아닙니다.

- 입력 공백, 길이, 줄 수, 연락처 차단 및 줄바꿈 보존
- 서로 다른 모델 응답 형태 처리 및 잘못된 JSON 거절
- 피드백 원문 순서 정렬, 정확한 문자열 위치 확인
- 없는 구절, 잘못된 줄, 중복 줄, 같은 문자열의 모호한 위치, 과도한 설명 거절
- 앞 구절 수정 후 다음 피드백은 미완료 유지
- 직접 수정에서 줄 수가 바뀌어도 뒤 원문 위치 보존
- 이전 선택을 원문 유지로 바꿀 때 재작성·중복 반영 없음
- AI 호출은 전체 분석에 1회만 발생 (mock 호출 횟수 검증)
- JSDOM 화면 버튼 흐름: 입력 → 첫 제안 수용 → 이전으로 돌아가 유지 → 둘째 제안 직접 수정 → 최종 결과 → 복사
- 새 DOM에서 임시 저장된 최종 결과 복원
- 오류 후 입력 유지 및 다시 분석 버튼 활성화
- 인증, 다른 Origin 거절, Free 미확인 상태 차단
- 한도/AI JSON 실패에 한국어 오류 표시, 예시 피드백으로 대체하지 않음
- 교사 코드 추측 제한, 전역 일일/동시 3건 한도

`npx wrangler deploy --dry-run` **성공**. Worker 번들과 AI / Assets / SQLite Durable Object 바인딩 구성을 확인했습니다. dry-run은 Cloudflare에 배포하거나 AI를 실행하는 명령이 아닙니다.

## 아직 실행하지 못한 검증

Cloudflare 대시보드가 로그인 화면인 상태이므로 다음은 **미확인**입니다.

- 실제 Worker 배포 및 HTTPS URL
- 실제 AI 호출 성공과 Qwen3 JSON Mode 지원
- 한국어 첨삭의 품질, 역사 정확성, 의도 보존, 불필요한 수정 정도
- 10~20명 실사용 및 실제 대기 시간, 실제 Neurons
- 실제 브라우저에서의 화면 렌더링/모바일 가로 넘침/터치
- 실제 클립보드 권한 (DOM 테스트에서는 clipboard stub 사용)
- 실제 네트워크/AI 제공업체 한도 초과 응답

Playwright 패키지는 있으나 실행용 Chromium이 이 환경에 없어 실제 브라우저 자동 테스트는 실행하지 않았습니다. JSDOM 테스트는 실제 브라우저 렌더링 검증을 대체하지 않습니다.

## 관찰 후 수정한 문제

- 엄격한 CSP에서 인라인 진행률 스타일이 막힐 수 있어 표준 `<progress>` 요소로 변경했습니다.
- 응답 시간 초과 직후 동시 처리 lease를 즉시 해제하면 아직 끝나지 않은 모델 요청과 겹칠 수 있어, timeout일 때 만료 시간까지 유지하게 수정했습니다.
- UI 테스트 초기 환경에서 `location` 누락과 재로드 시 구 이벤트 리스너 잔존 문제를 고쳤습니다. 실제 새 DOM으로 재로드 검증하며 JavaScript 오류도 실패로 집계합니다.

## 실제 AI 품질 시험 준비

`tests/quality-cases.json`에 좋은 가사, 여러 개선 사항, 짧은 가사, 긴 가사, 운율 중심, 문장 길이 불균형, 역사 확인 필요, 모호한 의도, 프롬프트 주입, 입력 한도 초과 사례가 있습니다. `npm run test:live`는 실제 배포된 API를 호출하여 `test-results/live-quality.json`을 기록합니다. 아직 이 결과 파일은 생성되지 않았습니다.

실제 출력은 사람도 검토해야 합니다. 좋은 가사에 억지 수정이 없는지, 역사 자료 밖의 사실을 만들어내지 않는지, 수정 이유가 초6 수준인지, 구절 위치가 정확한지 확인한 뒤 공개수업 사용 여부를 결정합니다.
