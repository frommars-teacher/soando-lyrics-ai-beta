# 소안도 가사 첨삭 AI — 독립 베타

**현재 상태: 소스 구현 및 로컬 자동 검증 완료. Cloudflare 인증·배포·실제 모델 호출 검증은 아직 완료되지 않았습니다. 학생에게 배포할 수 있는 완성품으로 보고하지 않습니다.**

이 저장소는 `frommars-teacher/soando-lyrics-ai-beta` 전용입니다. 기존 가사 사이트의 코드, 설정, 데이터에 접근하거나 변경하지 않습니다.

## 동작

Cloudflare Worker가 정적 화면과 `/api/analyze`를 같은 HTTPS 주소에서 제공합니다. 서버의 `AI` 바인딩으로 `@cf/qwen/qwen3-30b-a3b-fp8`를 호출합니다. 브라우저에 API 키는 없고, 별도 OpenAI 계정도 필요하지 않습니다. **현재는 교사 테스트 전용**이며 접속 코드는 교사에게만 제공해야 합니다.

- 전체 가사 분석 1회 → 최대 6개 제안 → 원문 위치를 검증하고 순서대로 표시
- AI 수정 수용 / 직접 수정 / 원문 유지 / 이전 선택 변경
- 원본의 위치와 항목별 선택을 보관하므로 앞쪽 수정이 뒤쪽 위치를 바꾸지 않음
- 원본과 최종 가사 비교, 변경 표시, 복사, Suno 링크
- 브라우저 임시 저장, 새로고침 복원, 한국어 오류 안내
- 사진 업로드/OCR은 미구현. 손글씨 한국어 정확도 검증 전이므로 제외
- AI 미연결·실패 시 미리 만든 피드백으로 대체하지 않음

## 배포 준비

1. 성인 교사 소유의 Cloudflare 계정에서 **Workers Free**를 확인합니다. Paid/AI Gateway 유료 크레딧을 사용하지 않습니다. 무료 이용을 위해 결제 수단을 등록할 필요는 없습니다. 기존 Paid 계정이라면 0원 보장으로 간주할 수 없습니다.
2. 이 저장소만 새 폴더에 내려받고 Node.js 22 이상에서 `npm ci`를 실행합니다.
3. `npx wrangler login`으로 Cloudflare에 로그인합니다. 권한 승인은 교사가 진행합니다.
4. `npx wrangler secret put TEACHER_CODE`로 충분히 긴 무작위 교사 전용 코드를 등록합니다. 코드·토큰을 GitHub나 채팅에 붙이지 않습니다.
5. Workers Free 확인 후 `wrangler.jsonc`의 `FREE_PLAN_CONFIRMED`만 `"true"`로 변경합니다. 이 설정 자체가 계정 플랜을 변경하거나 검증하는 것은 아닙니다.
6. `npm test`, `npx wrangler deploy --dry-run`, `npm run deploy`를 실행합니다. AI 및 SQLite Durable Object 바인딩은 설정에 포함되어 있습니다.
7. 출력된 `https://soando-lyrics-ai-beta.<계정별 하위도메인>.workers.dev` 주소에서 교사 코드로 접속하고 새 한국어 가사를 입력해 실제 분석을 확인합니다. 아직 실제 계정 URL은 확인되지 않았습니다.
8. 아래 실제 호출 시험을 실행하고 결과를 확인한 뒤 이 상태 문구를 갱신합니다. 별도로 실제 브라우저/PC·크롬북·태블릿에서 확인해야 합니다.

```sh
npm test
# 환경변수 BETA_URL, TEACHER_CODE를 안전하게 설정한 상태에서 실행
npm run test:live
```

Cloudflare Git 연동을 사용할 경우 **이 새 저장소만** 선택합니다. 최초 배포는 빈 빌드 명령, 배포 명령 `npx wrangler deploy`로 구성할 수 있습니다. `TEACHER_CODE`는 Worker secret으로 등록하고 코드에 넣지 않습니다. GitHub Pages 단독으로는 AI 바인딩을 사용할 수 없습니다.

## 비용 및 제한

Cloudflare Workers AI Free는 계정당 하루 10,000 Neurons, UTC 00:00(한국시간 09:00) 초기화입니다. Free는 초과 요청 실패이며 Paid는 초과 과금입니다.

선정 모델 공개 단가는 입력 100만 토큰당 4,625 Neurons, 출력 100만 토큰당 30,475 Neurons입니다. 입력 2,000 + 출력 1,500 토큰 가정 시 1회 약 **55 Neurons**, 20명 × 2회 = 약 **2,198 Neurons**입니다. 실제 한국어 토큰 수·생각 토큰·재시도로 달라지므로 측정 전 추정치입니다.

앱은 보수적 입력 바이트 추정과 최대 출력 2,500 토큰으로 호출 전 사용량을 예약합니다. 앱 자체 한도는 하루 최대 60요청/예약량 7,000 Neurons, 동시 3요청, 동일 네트워크 시간당 40요청입니다. 실패한 호출도 예약량에서 차감하며 자동 재시도하지 않습니다. 이 앱 밖의 같은 계정 사용량은 반영하지 못하므로 **무료 플랜 자체의 초과 차단**과 대시보드 모니터링이 필수입니다.

Dashboard → AI → Workers AI → Usage에서 수업 전후 Neurons를 확인합니다. 10~20명은 3명씩 분석 버튼을 누르는 방식으로 시험합니다. 대기열은 미구현이고 혼잡 시 재시도 안내가 표시됩니다. 실제 응답 속도·동시 학급 처리량은 미측정입니다.
